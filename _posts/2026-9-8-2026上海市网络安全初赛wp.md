## Baby_randomized_VM

是一个虚拟机程序，程序会读取输入的42个字符，然后做42组操作，每组针对输入的每一个字符。操作如下：

1. 把字符装进一个8位寄存器
2. 异或一个常数
3. 加一个常数
4. 循环左移若干位
5. 和目标值比较，不相等立马退出

42组全部通过后输出correct

反编译得到的main函数主要分为两段，前半段是读取输入和解密字节码，后半段是虚拟机的解释器。从解释器中我们可以知道乱序的操作码分别对应什么。

$$

## time_stream

```python
def xorshift32(x: int) -> int:
    x ^= (x << 13) & 0xFFFFFFFF
    x ^= x >> 17
    x ^= (x << 5) & 0xFFFFFFFF
    return x & 0xFFFFFFFF


def stream(seed: int, length: int) -> bytes:
    state = seed & 0xFFFFFFFF
    output = bytearray()
    while len(output) < length:
```

## echo_lwe

一个风味lwe加密系统，主要问题在于`derive_seed`中用的是`lable` 的前6个字节，而下面生成密钥算法中:

```python
secret = sample_small(master, b"secret-key")
raw_error = sample_small(master, b"secret-noise")
error = negacyclic_rotate(raw_error, rotation)

    while True:
        public_a = [secrets.randbelow(Q) for _ in range(N)]
        vulnerable_factor = public_a.copy()
        vulnerable_factor[rotation] = (vulnerable_factor[rotation] + 1) % Q
        if is_unit(vulnerable_factor):
            break

    public_b = add(negacyclic_mul(public_a, secret), error)
    return public_a, public_b, rotation
```

所以 $e_{raw}=s$，$e=x^r\cdot s$ ,下面的循环是确保 $a+x^r$ 可逆，然后另一半公钥$b=a\cdot s+e=(a+x^r)\cdot s \ \ mod \ \ q$ 

由于可逆，我们可以直接获得私钥$s=b\cdot (a+x^r)^{-1} mod\ \  q$ 

然后再按lwe加密标准流程解密即可

exp：

## nonce_again

AES-GCM重复使用了密钥和nonce，并给出了两组对应明密文和tag，需要根据目标明文，伪造密文和对应的tag

伪造密文是很容易的，因为key和nonce重用，只要将一组明密文xor即可获得GCM的密钥流，然后再用密钥流加密明文就行

难点在于tag，题目给出了GCM的ghash生成方式，通过查询资料可知GCM验证tag的生成方式为：

$$
	tag=ghash\oplus mask
$$

ghash:

```python
def ghash(h: int, aad: bytes, ciphertext: bytes) -> int:
    def blocks(data):
        padded = data + b"\0" * ((-len(data)) % 16)
        return [int.from_bytes(padded[i:i + 16], "big") for i in range(0, len(padded), 16)]

    value = 0
    for block in blocks(aad) + blocks(ciphertext):
        value = gf_mul(value ^ block, h)
    lengths = ((len(aad) * 8) << 64) | (len(ciphertext) * 8)
    return gf_mul(value ^ lengths, h)
```

这里的生成算法实际上是在有限域 $GF(2^{128})$ 上进行的，大概翻译过来就是：

$$
	gash=A_{1}H^3\oplus CH^2\oplus LH
$$

$A_{1}$ 是aad块，C是密文块，L是一个根据长度获得的块

将两个已知tag做xor，可以解出H：

$$
	tag_{1}\oplus tag_{2}=(C_{1}\oplus C_{2})\cdot H^2
$$

$$
	H^2=tag_{1}\oplus tag_{2}\cdot (C_{1}\oplus C_{2})^{-1}
$$

这是因为两次的aad和L都是相同的，所以能抵消掉

注意这里的求逆算法和开方都要在有限域上实现。获得H后，就可以计算target_ct对应的ghash，然后用一个已知tag计算固定的mask，就可以进一步计算目标tag了

最后用：

```python
def submission_flag(nonce: bytes, ciphertext: bytes, tag: bytes) -> str:
```
