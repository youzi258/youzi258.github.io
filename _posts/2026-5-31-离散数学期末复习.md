## 一、集合

### 1. 基本概念

集合是由确定对象组成的整体。集合中的对象称为元素。

- `a ∈ A`：`a` 是集合 `A` 的元素。
- `a ∉ A`：`a` 不是集合 `A` 的元素。
- `A ⊆ B`：`A` 是 `B` 的子集，即任意 `x ∈ A` 都有 `x ∈ B`。
- `A ⊂ B`：`A` 是 `B` 的真子集，即 `A ⊆ B` 且 `A ≠ B`。
- `∅`：空集，不含任何元素。
- `U`：全集，讨论范围内所有对象组成的集合。

常见表示法：

- 列举法：`A = {1, 2, 3}`。
- 描述法：`A = {x | x 是小于 10 的正偶数}`。
- 区间或条件表示：例如 `{x ∈ Z | x > 0}` 表示正整数集合。

重要结论：

- `∅ ⊆ A` 对任何集合 `A` 成立。
- `A ⊆ A` 对任何集合 `A` 成立。
- 如果有限集合 `A` 有 `n` 个元素，则幂集 `P(A)` 有 `2^n` 个元素。

### 2. 集合运算

设 `A`、`B` 是全集 `U` 的子集。

- 并集：`A ∪ B = {x | x ∈ A 或 x ∈ B}`。
- 交集：`A ∩ B = {x | x ∈ A 且 x ∈ B}`。
- 差集：`A - B = {x | x ∈ A 且 x ∉ B}`。
- 补集：`Ā = U - A`。
- 对称差：`A △ B = (A - B) ∪ (B - A)`。
- 笛卡儿积：`A × B = {(a, b) | a ∈ A 且 b ∈ B}`。

常用公式：

- 交换律：`A ∪ B = B ∪ A`，`A ∩ B = B ∩ A`。
- 结合律：`(A ∪ B) ∪ C = A ∪ (B ∪ C)`，`(A ∩ B) ∩ C = A ∩ (B ∩ C)`。
- 分配律：`A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)`。
- 分配律：`A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)`。
- 德摩根律：`(A ∪ B)̄ = Ā ∩ B̄`，`(A ∩ B)̄ = Ā ∪ B̄`。
- 差集公式：`A - B = A ∩ B̄`。
- 吸收律：`A ∪ (A ∩ B) = A`，`A ∩ (A ∪ B) = A`。
- 包含判定：`A ⊆ B ⇔ A ∩ B = A ⇔ A ∪ B = B ⇔ A - B = ∅`。

### 3. 证明集合相等

常用方法有三种：

- 双包含法：证明 `A ⊆ B` 且 `B ⊆ A`。
- 元素法：任取 `x`，证明 `x ∈ A ⇔ x ∈ B`。
- 运算律法：用集合恒等式一步步化简。

证明时推荐写法：

```text
任取 x ∈ 左边。
根据定义推出 x 满足右边条件，所以 x ∈ 右边。
因此左边 ⊆ 右边。
同理证明右边 ⊆ 左边。
所以两集合相等。
```

### 4. 典型例题

例 1：证明 `A - (B ∪ C) = (A - B) ∩ (A - C)`。

解析：

```text
A - (B ∪ C)
= A ∩ (B ∪ C)̄
= A ∩ (B̄ ∩ C̄)
= (A ∩ B̄) ∩ (A ∩ C̄)
= (A - B) ∩ (A - C)
```

例 2：设 `A = {1, 2}`，`B = {a, b, c}`，求 `A × B` 的元素个数。

解析：`|A × B| = |A| · |B| = 2 · 3 = 6`。具体为 `{(1,a),(1,b),(1,c),(2,a),(2,b),(2,c)}`。

### 5. 自测题

1. 若 `A = {1,2,3}`，写出 `P(A)` 的元素个数。
2. 判断：`∅ ∈ {∅, {1}}` 是否成立？
3. 证明：`A ∩ (B - C) = (A ∩ B) - C`。
4. 若 `A ⊆ B`，判断 `A ∩ C ⊆ B ∩ C` 是否一定成立。

## 二、二元关系

### 1. 关系的定义与表示

设 `A`、`B` 是集合，`A × B` 的任意子集都称为从 `A` 到 `B` 的二元关系。若 `R ⊆ A × A`，则称 `R` 是集合 `A` 上的二元关系。

如果 `(a, b) ∈ R`，也可写作 `aRb`。

常见表示方式：

- 集合表示：`R = {(1,2), (2,3)}`。
- 关系矩阵：用 `0/1` 矩阵表示是否存在关系。
- 关系图：顶点表示元素，有向边 `a -> b` 表示 `(a,b) ∈ R`。

### 2. 关系的运算

逆关系：

```text
R^-1 = {(b, a) | (a, b) ∈ R}
```

复合关系：

```text
S ∘ R = {(a, c) | 存在 b，使得 (a,b) ∈ R 且 (b,c) ∈ S}
```

注意顺序：`S ∘ R` 表示先经过 `R`，再经过 `S`。

关系的幂：

- `R^1 = R`。
- `R^2 = R ∘ R`。
- `R^n = R^(n-1) ∘ R`。

### 3. 关系性质判定

设 `R` 是集合 `A` 上的关系。

| 性质 | 定义 | 矩阵/图判定 |
| --- | --- | --- |
| 自反 | 对任意 `a ∈ A`，都有 `aRa` | 主对角线全为 `1`；每个顶点有自环 |
| 反自反 | 对任意 `a ∈ A`，都没有 `aRa` | 主对角线全为 `0`；无自环 |
| 对称 | 若 `aRb`，则 `bRa` | 矩阵关于主对角线对称；边成对反向出现 |
| 反对称 | 若 `aRb` 且 `bRa`，则 `a = b` | 非对角位置不能同时成对为 `1` |
| 传递 | 若 `aRb` 且 `bRc`，则 `aRc` | 有路径 `a -> b -> c` 时必须有边 `a -> c` |

易错点：

- 反对称不是“没有对称边”，而是“不允许不同元素之间双向相关”。
- 一个关系可以既对称又反对称，例如恒等关系 `{(a,a) | a ∈ A}`。
- 传递性要检查所有两步路径，不能只看相邻几个元素。

### 4. 等价关系

若集合 `A` 上的关系 `R` 同时满足自反、对称、传递，则称 `R` 是等价关系。

等价类：

```text
[a] = {x ∈ A | xRa}
```

等价关系的重要结论：

- 任意元素 `a` 必属于自己的等价类 `[a]`。
- 两个等价类要么完全相等，要么互不相交。
- 所有等价类构成 `A` 的一个划分。
- 反过来，`A` 的任意划分都能确定一个等价关系：同一块中的元素互相关。

典型例子：

- 整数集合 `Z` 上定义 `aRb ⇔ a ≡ b (mod n)`，这是等价关系。
- 等价类是按除以 `n` 的余数分类。

### 5. 偏序关系

若集合 `A` 上的关系 `R` 同时满足自反、反对称、传递，则称 `R` 是偏序关系，记为 `(A, R)`。

常见偏序：

- 数集上的小于等于关系 `≤`。
- 集合族上的包含关系 `⊆`。
- 正整数上的整除关系 `|`，其中 `a | b` 表示 `a` 整除 `b`。

偏序中的元素：

- 极大元：没有比它更大的可比较元素。
- 最大元：它大于等于集合中所有元素。
- 极小元：没有比它更小的可比较元素。
- 最小元：它小于等于集合中所有元素。
- 上界：大于等于子集中所有元素的元素。
- 下界：小于等于子集中所有元素的元素。
- 最小上界：所有上界中的最小者，也叫上确界。
- 最大下界：所有下界中的最大者，也叫下确界。

易错点：

- 最大元若存在一定唯一，极大元可以有多个。
- 最小元若存在一定唯一，极小元可以有多个。
- 极大元不一定能和所有元素比较，最大元必须能和所有元素比较。

哈斯图画法：

1. 先画出偏序关系中的覆盖关系。
2. 去掉自环。
3. 去掉由传递性可以推出的边。
4. 小元素画在下方，大元素画在上方，箭头通常省略。

### 6. 典型例题

例 1：设 `A = {1,2,3}`，`R = {(1,1),(2,2),(3,3),(1,2),(2,1)}`。判断 `R` 是否为等价关系。

解析：

- 自反：`(1,1),(2,2),(3,3)` 都在 `R` 中，满足。
- 对称：`(1,2)` 与 `(2,1)` 成对出现，满足。
- 传递：因为 `1R2` 且 `2R1`，需要 `1R1`，有；`2R1` 且 `1R2`，需要 `2R2`，有；其他情况也满足。
- 所以 `R` 是等价关系。等价类为 `{1,2}` 和 `{3}`。

例 2：在 `{1,2,3,6}` 上定义整除关系 `|`。求极小元、最小元、极大元、最大元。

解析：

- `1` 整除所有元素，所以 `1` 是最小元，也是极小元。
- 所有元素都整除 `6`，所以 `6` 是最大元，也是极大元。

### 7. 自测题

1. 设 `A = {1,2,3}`，`R = {(1,1),(2,2),(3,3),(1,2),(2,3),(1,3)}`，判断 `R` 是否传递。
2. 判断恒等关系 `I_A = {(a,a) | a ∈ A}` 是否对称、反对称。
3. 在整数集合上，关系 `aRb ⇔ a - b` 是偶数，是否为等价关系？
4. 在 `P({1,2})` 上按 `⊆` 构成偏序，求最大元和最小元。

## 三、函数

### 1. 函数的定义

设 `A`、`B` 是非空集合，如果对每个 `a ∈ A`，都存在唯一的 `b ∈ B` 与之对应，则称 `f` 是从 `A` 到 `B` 的函数，记为：

```text
f: A -> B
```

其中：

- `A` 是定义域。
- `B` 是陪域。
- `{f(a) | a ∈ A}` 是值域，也叫像集。

注意：值域一定是陪域的子集，但不一定等于陪域。

### 2. 单射、满射、双射

单射：

```text
若 f(a1) = f(a2)，则 a1 = a2。
```

等价说法：不同的输入不会得到相同的输出。

满射：

```text
对任意 b ∈ B，存在 a ∈ A，使得 f(a) = b。
```

等价说法：陪域中每个元素都被映到。

双射：

```text
f 既是单射又是满射。
```

双射的重要意义：函数存在反函数。

### 3. 复合函数与逆函数

若 `f: A -> B`，`g: B -> C`，则复合函数 `g ∘ f: A -> C` 定义为：

```text
(g ∘ f)(a) = g(f(a))
```

注意顺序：`g ∘ f` 表示先做 `f`，再做 `g`。

逆函数：

- 只有双射才存在反函数。
- 若 `f(a) = b`，则 `f^-1(b) = a`。
- `f^-1 ∘ f = I_A`，`f ∘ f^-1 = I_B`。

### 4. 有限集合上的判定技巧

设 `A`、`B` 是有限集合。

- 若 `|A| > |B|`，则不存在从 `A` 到 `B` 的单射。
- 若 `|A| < |B|`，则不存在从 `A` 到 `B` 的满射。
- 若 `|A| = |B|`，则单射、满射、双射三者可以互相推出。

### 5. 典型例题

例 1：判断 `f: Z -> Z`，`f(x) = 2x + 1` 是否单射、满射。

解析：

- 单射：若 `f(a)=f(b)`，则 `2a+1=2b+1`，所以 `a=b`，是单射。
- 满射：值域只包含奇数，不包含偶数，所以不是满射。

例 2：设 `f: R -> R`，`f(x)=x^3`。判断是否存在反函数。

解析：`x^3` 在实数上严格单调，既单射又满射，因此是双射，存在反函数 `f^-1(x)=三次方根 x`。

### 6. 自测题

1. 判断 `f: R -> R`，`f(x)=x^2` 是否单射、满射。
2. 若 `A={1,2,3}`，`B={a,b}`，是否可能存在从 `A` 到 `B` 的单射？
3. 若 `f: A -> B` 和 `g: B -> C` 都是双射，判断 `g ∘ f` 是否双射。
4. 若 `f: A -> B` 有反函数，说明 `f` 必须满足什么性质。

## 四、图的基本概念

### 1. 图的组成

图通常记为 `G = (V, E)`，其中：

- `V` 是顶点集合。
- `E` 是边集合。

常见类型：

- 无向图：边没有方向。
- 有向图：边有方向。
- 简单图：无自环、无重边的无向图。
- 多重图：允许重边。
- 完全图 `K_n`：任意两个不同顶点之间都有边。
- 子图：顶点和边都来自原图的图。
- 补图：在同一顶点集上，原图没有的边构成补图。

完全图边数：

```text
K_n 的边数 = n(n-1)/2
```

### 2. 度数与握手定理

无向图中，顶点 `v` 的度数 `deg(v)` 是与 `v` 关联的边数。自环通常贡献 2 度。

握手定理：

```text
Σ deg(v) = 2|E|
```

重要推论：

```text
无向图中奇度顶点个数一定为偶数。
```

有向图中：

- 入度：指向该顶点的边数。
- 出度：从该顶点出发的边数。

公式：

```text
Σ 入度 = Σ 出度 = |E|
```

### 3. 通路、回路与连通性

- 通路：顶点和边交替出现的序列，相邻顶点之间有边。
- 回路：起点和终点相同的通路。
- 简单路径：通常指顶点不重复的路径。
- 简单回路：除起点和终点相同外，其余顶点不重复。
- 连通图：无向图中任意两个顶点之间都有路径。
- 连通分量：极大的连通子图。

易错点：

- “路径是否允许重复顶点”要看教材定义，考试中按题目说明。
- 判断欧拉图时通常要求忽略孤立点后相关部分连通。
- 简单图中，`n` 个顶点的最大度数是 `n-1`。

### 4. 典型例题

例 1：一个无向图有 6 个顶点，度数分别为 `1,2,2,3,4,4`，问这样的图是否可能存在？

解析：度数和为 `1+2+2+3+4+4=16`，是偶数，不违反握手定理。但这只是必要条件，还要进一步构造或用图序列判定。期末基础题中若只问“是否违反握手定理”，答案是不违反。

例 2：完全图 `K_5` 有多少条边？

解析：`5·4/2 = 10` 条。

### 5. 自测题

1. 无向图的度数和为 15 是否可能？
2. `K_6` 有多少条边？
3. 有向图有 8 条边，则所有顶点入度之和是多少？
4. 一个无向图有 4 个奇度顶点，是否违反握手定理？

## 五、欧拉图与哈密顿图

### 1. 欧拉通路与欧拉回路

欧拉通路：经过图中每条边恰好一次的通路。  
欧拉回路：经过图中每条边恰好一次且起点等于终点的回路。  
欧拉图：含有欧拉回路的图。

无向图判定：

- 连通无向图存在欧拉回路 ⇔ 每个顶点度数都是偶数。
- 连通无向图存在欧拉通路但不存在欧拉回路 ⇔ 恰有两个奇度顶点。
- 若奇度顶点超过两个，则不存在欧拉通路。

有向图判定：

- 有向图存在欧拉回路：每个顶点入度等于出度，并且所有非零度顶点在连通意义上属于同一部分。
- 有向图存在欧拉通路：一个顶点满足 `出度 = 入度 + 1`，一个顶点满足 `入度 = 出度 + 1`，其余顶点入度等于出度，并且相关顶点连通。

### 2. 哈密顿通路与哈密顿回路

哈密顿通路：经过图中每个顶点恰好一次的通路。  
哈密顿回路：经过图中每个顶点恰好一次并回到起点的回路。  
哈密顿图：含有哈密顿回路的图。

与欧拉图不同，哈密顿图没有简单通用的充要判定。考试中常见方法：

- 直接构造一个经过所有顶点的回路。
- 证明不存在，例如删去某些顶点后连通分量过多。
- 使用充分条件。

常用充分条件：

- Dirac 定理：设 `G` 是有 `n ≥ 3` 个顶点的简单图，若每个顶点度数都至少为 `n/2`，则 `G` 有哈密顿回路。
- Ore 定理：设 `G` 是有 `n ≥ 3` 个顶点的简单图，若任意两个不相邻顶点 `u,v` 都满足 `deg(u)+deg(v) ≥ n`，则 `G` 有哈密顿回路。

注意：这些是充分条件，不满足条件不代表一定没有哈密顿回路。

### 3. 欧拉与哈密顿对比

| 对比项 | 欧拉 | 哈密顿 |
| --- | --- | --- |
| 关注对象 | 边 | 顶点 |
| 要求 | 每条边恰好一次 | 每个顶点恰好一次 |
| 判定难度 | 有明确度数判定 | 一般较难，无简单充要条件 |
| 常用方法 | 看奇度顶点个数 | 构造、反证、充分条件 |

### 4. 典型例题

例 1：某连通无向图顶点度数为 `2,2,2,4,4`，判断是否有欧拉回路。

解析：所有顶点度数都是偶数，且图连通，所以存在欧拉回路。

例 2：某连通无向图顶点度数为 `1,2,2,3,4`，判断是否有欧拉通路。

解析：奇度顶点为度数 `1` 和 `3` 的两个顶点，恰有两个奇度顶点，所以存在欧拉通路，但不存在欧拉回路。

例 3：简单图有 `n=6` 个顶点，最小度数为 `3`。能否推出有哈密顿回路？

解析：因为 `n/2 = 3`，最小度数 `δ(G)=3 ≥ n/2`，由 Dirac 定理可推出有哈密顿回路。

### 5. 自测题

1. 连通无向图有 0 个奇度顶点，是否存在欧拉回路？
2. 连通无向图有 4 个奇度顶点，是否存在欧拉通路？
3. 有向图中每个顶点入度都等于出度，是否一定有欧拉回路？
4. 不满足 Dirac 条件的图是否一定不是哈密顿图？

## 六、命题逻辑基本概念与等值演算

### 1. 命题与联结词

命题是能够判断真假的陈述句。疑问句、祈使句、含糊不确定的句子通常不是命题。

常用联结词：

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| `¬p` | 否定 | 非 `p` |
| `p ∧ q` | 合取 | `p` 且 `q` |
| `p ∨ q` | 析取 | `p` 或 `q`，通常为相容或 |
| `p -> q` | 蕴含 | 若 `p` 则 `q` |
| `p <-> q` | 等价 | `p` 与 `q` 同真同假 |

蕴含 `p -> q` 只有在 `p` 真、`q` 假时为假，其余情况均为真。

### 2. 公式类型

- 重言式：所有赋值下都为真。
- 矛盾式：所有赋值下都为假。
- 可满足式：至少存在一个赋值使其为真。

关系：

- 重言式一定可满足。
- 矛盾式不可满足。
- 非重言式不一定是矛盾式。

### 3. 常用等值式

基本等值：

- `p -> q ≡ ¬p ∨ q`。
- `p <-> q ≡ (p -> q) ∧ (q -> p)`。
- `p <-> q ≡ (p ∧ q) ∨ (¬p ∧ ¬q)`。

德摩根律：

- `¬(p ∧ q) ≡ ¬p ∨ ¬q`。
- `¬(p ∨ q) ≡ ¬p ∧ ¬q`。

双重否定：

- `¬¬p ≡ p`。

分配律：

- `p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)`。
- `p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r)`。

吸收律：

- `p ∨ (p ∧ q) ≡ p`。
- `p ∧ (p ∨ q) ≡ p`。

常量律：

- `p ∨ 1 ≡ 1`，`p ∧ 1 ≡ p`。
- `p ∨ 0 ≡ p`，`p ∧ 0 ≡ 0`。

### 4. 范式

析取范式：若干合取项的析取，例如：

```text
(p ∧ ¬q) ∨ (¬p ∧ r)
```

合取范式：若干析取项的合取，例如：

```text
(p ∨ q) ∧ (¬p ∨ r)
```

主析取范式：

- 每个合取项都包含全部命题变元。
- 每个变元只出现一次。
- 通常由真值表中公式取真值 `1` 的行得到。

主合取范式：

- 每个析取项都包含全部命题变元。
- 每个变元只出现一次。
- 通常由真值表中公式取真值 `0` 的行得到。

### 5. 典型例题

例 1：化简 `(p -> q) ∧ p`。

解析：

```text
(p -> q) ∧ p
≡ (¬p ∨ q) ∧ p
≡ (p ∧ ¬p) ∨ (p ∧ q)
≡ 0 ∨ (p ∧ q)
≡ p ∧ q
```

例 2：判断公式 `p -> (q -> p)` 是否为重言式。

解析：

```text
p -> (q -> p)
≡ ¬p ∨ (¬q ∨ p)
≡ (¬p ∨ p) ∨ ¬q
≡ 1 ∨ ¬q
≡ 1
```

所以是重言式。

### 6. 自测题

1. 将 `¬(p ∨ q)` 化为只含 `¬`、`∧` 的形式。
2. 判断 `p ∨ ¬p` 是什么类型的公式。
3. 化简 `p ∧ (p ∨ q)`。
4. 将 `p -> q` 改写为不含蕴含符号的公式。

## 七、命题逻辑推理理论

### 1. 推理有效性

推理形式：

```text
前提1, 前提2, ..., 前提n ⊢ 结论
```

推理有效的含义：当前提全真时，结论必真。

判定方法：

- 真值表法：检查所有前提都为真的行，结论是否都为真。
- 等值演算法：证明 `(前提1 ∧ ... ∧ 前提n) -> 结论` 是重言式。
- 推理规则法：从前提出发，逐步推出结论。

### 2. 常用推理规则

| 规则 | 形式 |
| --- | --- |
| 假言推理 | `p -> q, p ⊢ q` |
| 拒取式 | `p -> q, ¬q ⊢ ¬p` |
| 析取三段论 | `p ∨ q, ¬p ⊢ q` |
| 假言三段论 | `p -> q, q -> r ⊢ p -> r` |
| 合取引入 | `p, q ⊢ p ∧ q` |
| 合取消去 | `p ∧ q ⊢ p`，`p ∧ q ⊢ q` |
| 析取引入 | `p ⊢ p ∨ q` |
| 化简 | `p ∧ q ⊢ p` |

常见错误：

- 肯定后件谬误：由 `p -> q` 和 `q` 推出 `p`，无效。
- 否定前件谬误：由 `p -> q` 和 `¬p` 推出 `¬q`，无效。

### 3. 典型例题

例：证明 `p -> q, q -> r, p ⊢ r`。

证明：

```text
1. p -> q        前提
2. q -> r        前提
3. p             前提
4. q             由 1,3 假言推理
5. r             由 2,4 假言推理
```

### 4. 自测题

1. 判断 `p -> q, q ⊢ p` 是否有效。
2. 证明 `p ∧ q ⊢ q ∧ p`。
3. 判断 `p -> q, ¬q ⊢ ¬p` 是否有效。
4. 证明 `p -> q, q -> r ⊢ p -> r`。

## 八、一阶逻辑基本概念

### 1. 谓词、个体与量词

一阶逻辑比命题逻辑更细致，能表达对象及对象性质。

- 个体常元：表示具体对象，如 `a`、`b`。
- 个体变元：表示任意对象，如 `x`、`y`。
- 谓词：表示性质或关系，如 `P(x)`、`R(x,y)`。
- 函数符号：表示对象到对象的对应，如 `f(x)`。
- 论域：变量取值的范围。

量词：

- 全称量词：`∀x P(x)`，表示所有 `x` 都满足 `P`。
- 存在量词：`∃x P(x)`，表示至少存在一个 `x` 满足 `P`。

### 2. 自由变元与约束变元

在 `∀x P(x)` 或 `∃x P(x)` 中，`x` 被量词约束，称为约束变元。

没有被相应量词约束的变量称为自由变元。

例：

```text
∀x R(x, y)
```

其中 `x` 是约束变元，`y` 是自由变元。

含自由变元的公式通常不是命题，只有给自由变元赋值或加上量词后才有确定真假。

### 3. 自然语言翻译

常见表达：

- “所有 A 都是 B”：`∀x(A(x) -> B(x))`。
- “有些 A 是 B”：`∃x(A(x) ∧ B(x))`。
- “没有 A 是 B”：`¬∃x(A(x) ∧ B(x))`，也可写作 `∀x(A(x) -> ¬B(x))`。
- “不是所有 A 都是 B”：`¬∀x(A(x) -> B(x))`，等价于 `∃x(A(x) ∧ ¬B(x))`。

易错点：

- 全称句通常用蕴含 `->`。
- 存在句通常用合取 `∧`。
- `∀x(A(x) ∧ B(x))` 表示所有对象都是 A 且都是 B，通常太强。
- `∃x(A(x) -> B(x))` 很弱，因为不是 A 的对象会使命题自动为真。

### 4. 典型例题

例：论域为全体学生，`P(x)` 表示“x 认真复习”，`Q(x)` 表示“x 通过考试”。翻译“所有认真复习的学生都能通过考试”。

解析：

```text
∀x(P(x) -> Q(x))
```

例：翻译“有些学生没有认真复习但通过了考试”。

```text
∃x(¬P(x) ∧ Q(x))
```

### 5. 自测题

1. 翻译“所有偶数都能被 2 整除”。
2. 翻译“存在一个学生喜欢离散数学”。
3. 判断 `∀x(P(x) ∧ Q(x))` 与 `∀xP(x) ∧ ∀xQ(x)` 是否等价。
4. 判断 `∃x(P(x) -> Q(x))` 是否适合表达“有些 P 是 Q”。

## 九、一阶逻辑等值演算和推理

### 1. 量词否定

最重要的量词等值式：

```text
¬∀x P(x) ≡ ∃x ¬P(x)
¬∃x P(x) ≡ ∀x ¬P(x)
```

含义：

- “并非所有人都及格”等价于“至少有一个人不及格”。
- “不存在反例”等价于“所有对象都不是反例”。

### 2. 量词分配

一定成立：

```text
∀x(P(x) ∧ Q(x)) ≡ ∀xP(x) ∧ ∀xQ(x)
∃x(P(x) ∨ Q(x)) ≡ ∃xP(x) ∨ ∃xQ(x)
```

一般不成立：

```text
∀x(P(x) ∨ Q(x)) ≠ ∀xP(x) ∨ ∀xQ(x)
∃x(P(x) ∧ Q(x)) ≠ ∃xP(x) ∧ ∃xQ(x)
```

变量不自由出现时的常用等值：

- 若 `x` 不在 `Q` 中自由出现，则 `∀x(P(x) ∧ Q) ≡ ∀xP(x) ∧ Q`。
- 若 `x` 不在 `Q` 中自由出现，则 `∃x(P(x) ∨ Q) ≡ ∃xP(x) ∨ Q`。

### 3. 量词辖域与换名

量词辖域是量词作用的公式范围。变换公式时要避免变量混淆。

约束变元可以换名：

```text
∀x P(x) ≡ ∀y P(y)
```

但换名不能捕获原本自由的变量。例如在含自由变量 `y` 的公式中，不能随意把 `x` 换成 `y`，否则会改变含义。

### 4. 一阶逻辑推理规则

全称实例化：

```text
∀x P(x) ⊢ P(a)
```

全称推广：

```text
若能对任意对象 x 证明 P(x)，则可推出 ∀x P(x)
```

存在实例化：

```text
∃x P(x) 可引入新的常元 c，使 P(c) 成立
```

限制：`c` 必须是新的，不能是已有特定对象。

存在推广：

```text
P(a) ⊢ ∃x P(x)
```

### 5. 典型例题

例 1：证明 `∀x(P(x) -> Q(x)), ∀xP(x) ⊢ ∀xQ(x)`。

证明：

```text
1. ∀x(P(x) -> Q(x))       前提
2. ∀xP(x)                 前提
3. 任取个体 a
4. P(a) -> Q(a)            由 1 全称实例化
5. P(a)                    由 2 全称实例化
6. Q(a)                    由 4,5 假言推理
7. ∀xQ(x)                  由 3-6 全称推广
```

例 2：化简 `¬∀x(P(x) -> Q(x))`。

解析：

```text
¬∀x(P(x) -> Q(x))
≡ ∃x ¬(P(x) -> Q(x))
≡ ∃x ¬(¬P(x) ∨ Q(x))
≡ ∃x(P(x) ∧ ¬Q(x))
```

含义：存在某个对象满足 `P` 但不满足 `Q`。

### 6. 自测题

1. 化简 `¬∃x(P(x) ∧ Q(x))`。
2. 判断 `∀x(P(x) ∨ Q(x))` 是否等价于 `∀xP(x) ∨ ∀xQ(x)`。
3. 由 `∀xP(x)` 能否推出 `∃xP(x)`？需要什么前提？
4. 证明 `∀x(P(x) -> Q(x)), ∃xP(x) ⊢ ∃xQ(x)`。

## 十、综合易错点

- `∈` 表示元素属于集合，`⊆` 表示集合包含关系。例：若 `A={1,{2}}`，则 `{2} ∈ A`，但 `{2} ⊆ A` 不成立。
- `P(A)` 是集合的集合。若 `A={1,2}`，则 `P(A)={∅,{1},{2},{1,2}}`。
- `A × B` 与 `B × A` 一般不同，除非元素结构刚好相同且顺序不影响讨论。
- 反对称不是“不对称”。恒等关系既对称又反对称。
- 传递性要检查所有 `aRb` 和 `bRc` 组合，不是只看是否有三角形。
- 等价关系对应划分；偏序关系对应“可比较的顺序结构”。
- 极大元可以有多个，最大元若存在只能有一个。
- 欧拉图看边是否能一次走完，关键是顶点度数。
- 哈密顿图看点是否能一次走完，通常需要构造或用充分条件。
- `p -> q` 不表示因果，只表示真值关系；当前件假时蕴含式为真。
- 不能由 `p -> q` 和 `q` 推出 `p`。
- 不能由 `p -> q` 和 `¬p` 推出 `¬q`。
- 全称命题翻译常用 `->`，存在命题翻译常用 `∧`。
- `¬∀` 变 `∃¬`，`¬∃` 变 `∀¬`。
- 存在实例化引入的常元必须是新的，不能偷换成已有对象。

## 十一、期末题型与答题模板

### 1. 集合证明题

模板：

```text
证明 A = B。
任取 x ∈ A，推出 x ∈ B，所以 A ⊆ B。
任取 x ∈ B，推出 x ∈ A，所以 B ⊆ A。
因此 A = B。
```

如果题目适合公式法，优先使用集合运算律，步骤更简洁。

### 2. 关系性质判定题

模板：

```text
自反：检查所有 (a,a) 是否都属于 R。
对称：检查每个 (a,b) 是否都有 (b,a)。
反对称：检查不同元素 a,b 是否存在双向关系。
传递：检查若 (a,b),(b,c) ∈ R，是否必有 (a,c) ∈ R。
结论：列出满足和不满足的性质。
```

### 3. 等价关系与偏序题

等价关系模板：

```text
分别证明自反、对称、传递。
若三者都成立，则为等价关系。
再按 [a] = {x | xRa} 求等价类。
```

偏序关系模板：

```text
分别证明自反、反对称、传递。
若三者都成立，则为偏序关系。
画哈斯图时去自环、去传递边、保留覆盖关系。
```

### 4. 欧拉图判定题

模板：

```text
先说明图是否连通。
统计奇度顶点个数。
0 个奇度顶点：有欧拉回路。
2 个奇度顶点：有欧拉通路但无欧拉回路。
超过 2 个奇度顶点：无欧拉通路。
```

### 5. 哈密顿图判定题

模板：

```text
若能构造经过所有顶点一次的回路，则说明是哈密顿图。
若用充分条件，先说明图是 n ≥ 3 的简单图，再验证最小度数或 Ore 条件。
若证明不存在，常用反证或割点/连通分量思想。
```

### 6. 命题逻辑等值演算题

模板：

```text
先消去 -> 和 <->。
再用德摩根律把否定推进到命题变元前。
再用分配律化为析取范式或合取范式。
最后用吸收律、幂等律、矛盾律化简。
```

### 7. 一阶逻辑翻译题

模板：

```text
确定论域。
定义谓词。
判断是全称句还是存在句。
全称句通常写成 ∀x(条件 -> 结论)。
存在句通常写成 ∃x(条件 ∧ 结论)。
检查量词辖域和变量是否一致。
```

## 十三、答案与解析

### 1. 各章自测题答案

集合：

1. `|P(A)| = 2^3 = 8`。
2. 成立，因为 `{∅,{1}}` 的一个元素就是 `∅`。
3. `A ∩ (B - C) = A ∩ (B ∩ C̄) = (A ∩ B) ∩ C̄ = (A ∩ B) - C`。
4. 一定成立。若 `x ∈ A ∩ C`，则 `x ∈ A` 且 `x ∈ C`；由 `A ⊆ B` 得 `x ∈ B`，所以 `x ∈ B ∩ C`。

二元关系：

1. 传递。因为有 `(1,2)` 和 `(2,3)`，且 `(1,3)` 已在 `R` 中；其他组合也不破坏传递性。
2. 恒等关系既对称又反对称。
3. 是等价关系。自反：`a-a=0` 是偶数；对称：若 `a-b` 是偶数，则 `b-a` 是偶数；传递：若 `a-b`、`b-c` 是偶数，则 `a-c` 是偶数。
4. 最大元是 `{1,2}`，最小元是 `∅`。

函数：

1. `f(x)=x^2` 在 `R -> R` 上不是单射，因为 `f(1)=f(-1)`；也不是满射，因为负数没有原像。
2. 不可能，因为 `|A|>|B|`。
3. 是双射。双射的复合仍为双射。
4. 必须是双射。

图的基本概念：

1. 不可能。无向图度数和必须为偶数。
2. `K_6` 有 `6·5/2=15` 条边。
3. 入度之和为 `8`。
4. 不违反。奇度顶点个数为 4，是偶数。

欧拉图与哈密顿图：

1. 存在欧拉回路。
2. 不存在欧拉通路，因为奇度顶点超过两个。
3. 不一定，还需要相关连通性条件。
4. 不一定。Dirac 条件是充分条件，不是必要条件。

命题逻辑：

1. `¬p ∧ ¬q`。
2. 重言式。
3. `p`。
4. `¬p ∨ q`。

命题逻辑推理：

1. 无效，这是肯定后件谬误。
2. 由 `p ∧ q` 合取消去得 `p` 和 `q`，再合取引入得 `q ∧ p`。
3. 有效，这是拒取式。
4. 假设 `p`，由 `p -> q` 得 `q`，由 `q -> r` 得 `r`，所以 `p -> r`。

一阶逻辑基本概念：

1. 可写为 `∀x(Even(x) -> DivisibleBy2(x))`。
2. 可写为 `∃x(Student(x) ∧ LikesDiscreteMath(x))`，若论域已限定为学生，则可写为 `∃x LikesDiscreteMath(x)`。
3. 等价。
4. 不适合。应写为 `∃x(P(x) ∧ Q(x))`。

一阶逻辑等值演算和推理：

1. `¬∃x(P(x) ∧ Q(x)) ≡ ∀x¬(P(x) ∧ Q(x)) ≡ ∀x(¬P(x) ∨ ¬Q(x))`。
2. 一般不等价。
3. 若论域非空，则可以推出；若允许空论域，则不能推出。
4. 由 `∃xP(x)` 取新常元 `c` 使 `P(c)`；由 `∀x(P(x)->Q(x))` 得 `P(c)->Q(c)`；推出 `Q(c)`；由存在推广得 `∃xQ(x)`。

### 2. 综合自测题答案

1. `A ∪ B={1,2,3,4}`，`A ∩ B={2,3}`，`A-B={1}`。
2. `P(A)={∅,{a},{b},{a,b}}`。
3. 是等价关系，等价类为 `{1,2}` 和 `{3}`。
4. 最小元为 `1`，最大元为 `6`。
5. 是双射。单射：`2a-3=2b-3` 推出 `a=b`；满射：任意 `y ∈ R`，取 `x=(y+3)/2`，则 `f(x)=y`。
6. 有欧拉回路，因为连通且所有顶点度数为偶数。
7. 有欧拉通路但无欧拉回路，因为恰有两个奇度顶点。
8. `¬(p -> q) ≡ ¬(¬p ∨ q) ≡ p ∧ ¬q`。
9. 有效。由 `p` 和 `p -> q` 得 `q`，再由 `q` 和 `q -> r` 得 `r`。
10. 设 `M(x)` 表示 `x` 喜欢数学，`D(x)` 表示 `x` 喜欢离散数学，论域为学生，则公式为 `∀x(M(x) -> D(x))`。若论域不是学生，还应写为 `∀x((Student(x) ∧ M(x)) -> D(x))`。
11. `¬∃x(P(x) ∨ Q(x)) ≡ ∀x¬(P(x) ∨ Q(x)) ≡ ∀x(¬P(x) ∧ ¬Q(x))`。
12. 一般不等价。左边要求同一个对象同时满足 `P` 和 `Q`；右边只要求存在某个对象满足 `P`，存在某个对象满足 `Q`，可以不是同一个对象。
